# 🚇 Metro Ticket Generation System in ServiceNow

<p align="center">

## 🎫 Smart • Digital • Automated Metro Ticketing

A ServiceNow-based application designed to simplify the metro ticket
generation process through digital journey management, fare calculation,
ticket generation, and QR-code-based digital tickets.

</p>

---

## 📌 Project Overview

The **Metro Ticket Generation System** is developed using the **ServiceNow platform** to provide a digital solution for metro ticket generation.

The system allows users to enter journey details, select their source and destination, calculate the applicable fare, select a payment method, and generate a digital metro ticket with a **QR code**.

The project demonstrates the use of ServiceNow application development, forms, tables, automation, and digital ticket generation.

---

## 🎯 Objectives

- 🚇 Digitize the metro ticket generation process.
- 🎫 Generate tickets electronically.
- 💰 Automate fare calculation.
- 📱 Generate QR codes for digital tickets.
- 📋 Maintain passenger and ticket information.
- ⚙️ Reduce manual effort in ticket generation.
- ✅ Provide a simple and user-friendly ticketing process.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| 👤 **Passenger Details** | Capture the required passenger information. |
| 🚇 **Journey Selection** | Select source and destination stations. |
| 💰 **Fare Calculation** | Calculate the fare based on journey details. |
| 💳 **Payment Selection** | Select the available payment method. |
| 🎫 **Ticket Generation** | Generate a digital metro ticket. |
| 📱 **QR Code Generation** | Generate a QR code for the digital ticket. |
| 📋 **Ticket Management** | Store and manage ticket-related information. |
